📊 雲端大數據處理流程 (Big Data Analytics)

本數據儀表板未來預計整合 AWS 原生的大數據分析服務，實現百萬級資料的即時運算：

  • Amazon Athena： 利用無伺服器的 SQL 查詢引擎，直接分析存放在 S3 的歷史違規開單 CSV 檔案，不需額外建立資料倉儲。
  • Amazon QuickSight： (進階功能) 將 Athena 的分析結果自動渲染為高互動性的 BI 商業智慧圖表，供決策者視覺化探索各地區的違規趨勢。
