全台科技執法點位與測速查詢平台

Team 奇蹟77

💡 專題核心動機與市場差異

市面上的「神盾」等測速 App 僅提供行車當下的單點語音警示，卻缺乏能讓民眾「事前查詢、鳥瞰全台各縣市取締熱區」的視覺化介面。我們利用 AWS 與警政署開放資料填補此市場空白，打造最直覺的執法地圖查詢平台。

🚀 核心功能預覽

  • 全台各縣市科技執法與測速點位查詢
  • 多維度篩選（取締類型、特定路段）
  • 全台罰單熱區大數據視覺化儀表板
  • （次要）GPS 接近預警功能

☁️ AWS 雲端賦能

全面採用 Serverless 架構 (Lambda, API Gateway) 降低成本，並使用 Location Service 實現核心的「地理圍欄 (Geofencing)」追蹤技術。

🔄 系統即時運作流程

📂

1. 資料自動同步

Lambda 定期抓取警政署 CSV 開放資料，清洗後更新至 DynamoDB。

⚡

3. API 快速響應

API Gateway 觸發 Lambda，從 DynamoDB 高速撈取匹配的點位座標。

▶
🗺️

4. 地圖渲染與熱區

透過 Amazon Location Service 將查詢結果以圖釘精準繪製於地圖上。

🎯 專案預期效益

  • 資訊公開透明： 提供最易用、最直覺的查詢介面，讓民眾清楚了解各路口的執法規範。
  • 提升行車安全意識： 透過事前查詢熱區，促使駕駛人在行經該路段時更加謹慎，減少違規與意外。
  • 推動交通資料治理： 透過大數據分析，協助交通單位找出「標線設計不良」導致頻繁違規的真正痛點。

💡 為什麼選擇 AWS Serverless？

  • 極低的維護成本： 充分利用 Lambda 與 API Gateway 的免費額度，不用 24 小時開啟伺服器燒錢。
  • 高併發處理能力： 遇到連續假期車潮湧現時，系統能自動彈性擴展，保證服務不崩潰。
  • 原生地理服務： Amazon Location Service 內建強大的 Geofence (地理圍欄) 引擎，比自行開發演算法更精準。
