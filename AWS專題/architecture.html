🔄 資料整合與流動管線 (Data Ingestion Pipeline)

本系統不僅提供前端查詢，背後的資料更新機制亦遵循雲端自動化原則設計：

1

政府開放資料獲取 (Open Data)

從內政部警政署資料平台下載「全台固定式測速照相」及「科技執法點位」最新 CSV 原始檔案。

2

Python 資料清洗與轉換 (Data ETL)

利用本地端或 AWS Glue 腳本，過濾掉遺失經緯度之無效資料，並將地址轉換為標準的 GeoJSON 或 DynamoDB JSON 格式。

3

匯入 Amazon DynamoDB

透過 AWS CLI 或 Boto3 腳本進行批次寫入 (BatchWriteItem)，將清洗後的高品質座標點位寫入雲端資料庫，供前端應用程式隨時高速檢索。
